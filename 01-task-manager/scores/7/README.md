## 主要问题

1. **任务 label 关联仍需修正。** 当前已经用 `label` 包裹复选框和文字，但仍保留 `htmlFor={task.id}`，复选框却没有对应的 `id`。显式的 `htmlFor` 会优先查找指定 ID，不会退回使用内部复选框。建议删除 `htmlFor`，使用包裹式隐式关联；或者给复选框添加 `id={task.id}`。
2. **当前筛选不可辨识。** All、Active、Completed 按钮缺少选中样式与 `aria-pressed`，用户无法直接确认当前筛选条件。
3. **任务输入框语义不完整。** 只有 placeholder，建议补充 label，并通过 `aria-invalid`、`aria-describedby` 关联错误信息。

上述问题应通过相应行为测试验证。另可删除遗留注释 `// Add task logic here`。当前规模使用单组件和直接计算筛选结果合理，无需增加全局状态或额外抽象。
